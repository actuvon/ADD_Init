# README
This is the Kanban board. All entries in this document are to be bite-sized items that could theoretically fit on a sticky note. Each entry should call out a more detailed markdown file in one of the folders `Active`, `TODO`, `Completed`, or `Archived`.

Any time we work on something, it should be related to an entry in this document. Any time we work on something, we should update the markdown file related to the task we are working on. The markdown files for each entry have a related Entry.journal.md file when they are more than 200 lines long, or otherwise warranting it, which keeps a chronological record of the work done on that entry. See `./ActiveTasks/Archived/ExampleTask.md` and `./ActiveTasks/Archived/ExampleTask.journal.md` .
